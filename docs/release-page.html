Lion Code

本地终端 AI 编码助手（MiMo TUI 前端 + 纯 Python 后端 · 云端模型）· v1.5.46

它是什么

在终端里工作的编码 Agent：读代码、改文件、跑命令、联网查资料、把大任务拆给子代理并行做。 模型走云端 API（OpenAI 兼容），不带本地权重、不下载模型。

安装与启动

1) 双击安装包 LionCode-Setup-1.0.0.exe
2) 装完【新开一个 cmd】（旧窗口认不到新 PATH ✗ 必须新开）
3) 输入:  lion-code
4) 首次使用先配云端:  /key <你的 API key>
安装在旧窗口里敲 lion-code 会报"不是内部或外部命令" —— Windows 的 cmd 只在启动那一刻读一次 PATH，装完必须重开一个窗口。

directory_tree目录树/看结构
glob_files按名字/后缀找文件
search_in_files文件内容里搜文本/正则
line_count数行数
write_file写文件（覆盖）
create_file新建文件（可带内容；不覆盖已有）
modify_file改文件（替换/插入/删除/追加）
append_file追加到末尾
copy_file复制文件/目录
create_directory建目录
delete_file删除（危险，需确认）
download_file下载（含 SSRF 闸门）
execute_command跑命令（PowerShell，含 git）
web_search联网搜索（bing 默认）
system_info本机系统信息
timestamp当前日期时间
context_window上下文窗口说明
context_prune上下文占用与建议
ask_user向你提问

另有插件工具 skill_load（载入技能）与子代理 agent_spawn / agent_team_run。

能力一览

批量工具调用一轮最多 10 个互不依赖的调用并行发
插队正在跑时发消息会打断当前任务并立刻接管（不再只是"会话正忙"被拒）
改动审核写文件前先给你 diff，通过才落盘，可打回让模型重写
子代理可查看状态（running/idle/completed/…）、可停止且级联停子代理
工作区多工作区管理；切换即生效（会话落进所选目录）

已知限制（如实）

① 界面偶发崩溃：上游 OpenTUI（Bun 1.4.2）有原生段错误，崩了会打印症状并提示 "重新打开即可"，数据不丢。
② 本沙箱类环境（Low 权限）安装时无法写用户 PATH → 日志会明确提示"需手动加"。
云端-only：不下载、不运行任何本地模型；密钥在界面里显示为掩码形式。
